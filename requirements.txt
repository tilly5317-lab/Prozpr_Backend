# >=1.4.8 is load-bearing for chat token streaming, not a routine floor. The
# answer arrives as a FORCED TOOL CALL, so incremental delivery needs the
# `fine-grained-tool-streaming-2025-05-14` beta, which the formatter passes as
# ChatAnthropic(betas=[...]) — a real field only from 1.4.x. On an older release
# the kwarg falls through to model_kwargs, the beta header never reaches the API,
# and Anthropic buffers the tool-call JSON to the end of the response: measured
# on an 8s answer, the first delta arrived at 7.44s vs 2.64s with the beta, which
# reads to a customer as "streaming is broken" while raising no error anywhere.
# The floor must stay ABOVE whatever prod last installed: deploy.yml reuses a
# long-lived venv and pip will not upgrade an already-satisfied requirement.
